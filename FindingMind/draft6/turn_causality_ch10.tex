Counting the column is instructive.  The constructions are numerous and
cheap; they say that the framework can \emph{express} the physics, which
was never seriously in doubt.  The theorems are fewer and are the reason
to care: each has a hypothesis that can fail, and each says that
something familiar from physics is forced by something structural about
computation.  The conjectures are the three places where the analogy is
currently doing work the mathematics has not yet done, and two of the
three concern the same missing object --- a generator.

\section{The Main Construction}

\begin{construction}[Decorated Reversible GSLT]
\label{con:main}
Given a GSLT $\GSLT = (\terms, \eqs, \rules)$, a semiring $\Semi$, a
refinement-complete decoration $\dec$, and a conversion system on the
resource kinds, define $\GSLT^{\dagger\dec}$ with:
\begin{itemize}[itemsep=2pt]
  \item terms the triples $\langle P, \trace, \vect{A}\rangle$, where
        $\vect{A}$ is a family of \emph{located} accounts, one per surface
        holding a stack;
  \item rules the forward steps (drawing $\dec_r(u)$ from the account at
        the drawing surface, recording the decoration in the trace) and
        their reversals;
  \item $\eqs$ lifted to the current-term component.
\end{itemize}
The extended HML of Definition~\ref{def:ext-modal} internalizes the
decoration as logical data.
\end{construction}

\begin{theorem}[What is conserved]
In $\GSLT^{\dagger\dec}$:
\begin{enumerate}[label=(\roman*)]
  \item \textbf{Ledger.}  Fuel remaining plus fuel recorded spent is
        invariant: $\sigma(t) + \kappa(t) = \sigma_0$
        (Proposition~\ref{thm:conservation}).  This holds by construction.
  \item \textbf{Value.}  If the conversion system is arbitrage-free, the
        total virtual-token value $\nu$ is invariant under every engine
        operation (Proposition~\ref{prop:firstlaw}); if it is lossy, $\nu$
        is a Lyapunov function and the honest scalar is free energy
        (Proposition~\ref{prop:secondlaw}).  This has a hypothesis and can
        fail.
  \item \textbf{Memory.}  Energy descends to the folded history exactly
        when the folded loops carry no holonomy
        (Theorem~\ref{thm:price}); conservation therefore sets a lower
        bound on retained history, coinciding with the Landauer bound
        (Remark~\ref{rmk:landauer}).
  \item \textbf{Time-reversal.}  Reversing the trace and applying the
        reversal $\dec^{\dagger}$ is an automorphism of
        $\GSLT^{\dagger\dec}$.
\end{enumerate}
Probability conservation is \emph{not} on this list.  Unitarity would
require the amplitudes at each state to be normalised and the paths to be
poolable, and Remark~\ref{rmk:obstruction} is the reason the second
condition is not available.
\end{theorem}

\section{From Construction to Code}

The construction is algorithmic at every stage.  For a given GSLT:

\begin{enumerate}[itemsep=4pt]
  \item \textbf{Represent terms} as algebraic data types in the
        implementation language.

  \item \textbf{Compute minimal contexts} via the Milner--Sewell--Leifer
        algorithm on the rewrite rules; store as a context lattice.

  \item \textbf{Evaluate HML formulae} against a term, and check
        refinement-completeness of the intended decoration domain --- if
        the most refined witness is not unique, the decoration is not
        well defined and the implementation will silently choose.

  \item \textbf{Attach the decoration} to each rule as a map from formula
        identifiers into the chosen semiring, together with the table
        updates if the decoration is dynamic.

  \item \textbf{Locate the accounts.}  Every stack lives on a channel;
        none floats free.  This is a correctness requirement, not an
        optimisation.

  \item \textbf{Extend terms with trace and accounts}, implementing
        forward and backward rules as the reversible rewrite system.

  \item \textbf{Simulate} in the stochastic instance via Gillespie:
        compute exit rates, sample the next transition and waiting time,
        advance the term, update the table, draw on the account, record
        the trace.
\end{enumerate}

Each step is a well-defined computational procedure, and steps 4--7 are
implemented in the simulation prototype for the specific case of MeTTaIL
rewrite rules~\cite{StochSim}.
